# Tools & Host Environment

## Built-in Tools
- File operations: `read_file`, `write_file`, `edit_file`.
- Search: `grep`, `find_files`, `list_dir`.
- Shell: `exec` with execution timeout.

## External Integrations
- `notion`: Notion workspace integration (@notionhq/notion-mcp-server).
- `mistral_ocr`: Mistral Document Intelligence API (4.x).
- `9router`: Local/Cloud LLM Gateway (`http://127.0.0.1:20128/v1`).
