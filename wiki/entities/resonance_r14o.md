## Intended Use

- TEOAE screening/diagnostic, DPOAE screening/diagnostic
- Cochlear functionality test via outer hair cell response
- Used by audiologists, hearing healthcare professionals, trained technicians
- Intended for medical environments with low background noise

## Key Specifications

| Parameter | Value |
|-----------|-------|
| **TEOAE stimulus** | 70–90 dB peSPL, 66 Hz, non-linear click |
| **TEOAE bandwidth** | 750 Hz – 5 kHz |
| **DPOAE F2/F1 ratio** | 1.22 |
| **DPOAE stimulus L2** | 35–70 dB SPL |
| **Artefact level** | 20–60 dB SPL (TEOAE), 20–40 dB SPL (DPOAE) |
| **Battery** | Li-ion 3.6 V / 3 Ah, up to 8 h normal use |
| **Dimensions** | 180 × 135 × 41 mm |
| **Weight** | 572 g |
| **Operating temp** | +15 °C to +35 °C |

## Accessories (standard)

- OAE probe (applied part, BF)
- Calibration cavity
- Kit tips for OAE probe
- Medical CE approved power supply (5 VDC)
- Charging cradle
- USB pen drive (DHR, MDS software, manual)
- Carrying bag
- Optional: Wi-Fi thermal printer, external USB keyboard

## Maintenance & Calibration

| Item | Requirement |
|------|-------------|
| **Daily** | Check probe performance in test cavity; visual inspection |
| **Calibration** | At least once per year by RESONANCE authorized personnel |
| **Probe tips** | Single-use only; replace between patients |
| **Housing** | Damp cloth, no aggressive agents; avoid liquid ingress |
| **Battery** | Replace only by qualified personnel; same type 1SPNCR-18650A |
| **Warranty** | 24 months device / 12 months accessories from installation |

## Safety Notes

- Applied parts: BF type per IEC 60601-1
- Not for use with flammable anesthetics/agents
- Do not immerse; no specific ingress protection
- Transducer replacement requires full recalibration
- Probe coupling must be verified before each test
