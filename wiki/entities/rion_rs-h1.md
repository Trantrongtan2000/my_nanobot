# Rion RS-H1 — Impedance Audiometer

## Device Info

| Field | Value |
|-------|-------|
| **Manufacturer** | Rion Co., Ltd. — 3-20-41 Higashimotomachi, Kokubunji, Tokyo 185-8533, Japan |
| **Website** | http://www.rion.co.jp/english/ |
| **Model** | RS-H1 |
| **Type** | Impedance audiometer (tympanometry + acoustic reflex) |

## Intended Use

- Tympanometry (226 Hz / 1000 Hz probe tone)
- Acoustic reflex tests: AUTO, MANUAL, ADD, DECAY, LATENCY
- Combined Tympanometry & Reflex test
- Measures eardrum mobility, middle ear pressure, equivalent volume, static compliance, gradient
- For use by trained personnel in quiet environment (soundproof chamber/audiometry room)

## Key Specifications

| Parameter | Value |
|-----------|-------|
| **Display** | 7-inch color LCD, 800 × 480 dpi, touch panel |
| **Printer** | Built-in thermal, 104 mm width, 832 dots/line, paper TP-42 |
| **Probe tone** | 226 Hz (85 dB) / 1000 Hz (75 dB) |
| **Pressure range** | -600 to +200 daPa (auto/manual/servo) |
| **Pressure speed** | 50 daPa/s (standard) or 200 daPa/s (high speed) |
| **Ear probe** | ET-05 with LED pressure/measurement indicator |
| **Earplug set** | RS-M1-S10, 15 sizes + cleaning wire |
| **Air-conduction earphone** | AD-06BF2 (code "AIR") |
| **Mechanical pump** | FB-22 (external, optional for Reflex test) |
| **Operating temp** | 15 °C to 35 °C |
| **Humidity** | 30% to 90% |
| **Atmospheric pressure** | 700 hPa to 1020 hPa |

## Test Modes

- **Tympanometry**: Normal (both ears) or 5-pattern mode
- **Reflex AUTO**: Automatic stimulus sequence
- **Reflex MANUAL**: Operator-controlled stimulus
- **Reflex ADD**: Cumulative reflex measurement
- **Reflex DECAY**: Reflex decay test
- **Reflex LATENCY**: Reflex latency measurement
- **Tympanometry & Reflex**: Continuous combined test

## Accessories

- Ear probe ET-05 with cord
- Earplug set RS-M1-S10 (15 sizes + cleaning wire)
- Air-conduction earphone AD-06BF2 with headband assembly
- Mechanical pump FB-22 (optional)
- Power cord
- Printer paper TP-42
- Optional: control button PO-02F, computer connection cable AA-M1-190

## Maintenance & Calibration

| Item | Requirement |
|------|-------------|
| **Daily** | Visual check of device and ear probe; check before every test |
| **Objective calibration** | At least once per year |
| **Ear probe calibration** | Use 2 mL cavity; verify before testing |
| **Cleaning ear probe** | Disinfecting alcohol before and after each test; clean channels with supplied tool |
| **Cleaning earplugs** | Disinfecting alcohol between patients |
| **Cleaning headband/earmuffs** | Disinfecting alcohol before and after each test |
| **Cleaning main unit** | Neutral detergent; no thinner/benzene/alcohol on LCD |
| **Printer paper** | TP-42 only; avoid vinyl chloride storage |
| **Fuse** | Rion-specified fuse only |

## Safety Notes

- Ear probe and air-conduction earphone are calibrated as a pair; serial numbers must match main unit
- Pressure dial must be monitored to avoid excessive pressure (eardrum injury risk)
- Do not connect non-FB-22 pumps to mechanical pump connector
- Earplugs are choking hazard for children; keep away from kids
- Not for use in oxygen/nitrous oxide or flammable anesthetic atmosphere
- Applied parts comply with IEC 60601-1 BF type
- Install outside patient environment per JIS T0601-1-1 Section 2.202
