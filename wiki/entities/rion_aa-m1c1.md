# Rion AA-M1C1 — Audiometer

## Device Info

| Field | Value |
|-------|-------|
| **Manufacturer** | Rion Co., Ltd. — 3-20-41 Higashimotomachi, Kokubunji, Tokyo 185-8533, Japan |
| **Website** | http://www.rion.co.jp/english/ |
| **Model** | AA-M1C1 |
| **Type** | General-purpose Type 3 (JIS T1201-1:2011), Type B (JIS T1201-2:2000) |
| **Standards** | JIS T1201-1:2011, JIS T1201-2:2000 |

## Intended Use

- Pure tone audiometry (air/bone conduction, manual/automatic)
- Screening audiometry
- Suprathreshold audiometry (SISI, ABLB)
- Bekesy audiometry (TTS, fixed-frequency)
- Speech audiometry (external input only)
- For use by trained personnel in quiet environment (soundproof chamber/audiometry room)

| Parameter | Value |
|-----------|-------|
| **Display** | 7-inch color LCD, 800 × 480 dpi, touch panel |
| **Printer** | Built-in thermal, 104 mm width, 832 dots/line, paper TP-42 |

## Accessories

- AC earphone AD-02BF1 with headband
- Bone vibrator BR-41 with headband
- Patient response switch PO-02F
- Monitor earphone (stereo inner earphone)
- Power cord
- Optional: microphone (talkback/talk-forward), CD player, computer connection cable AA-M1-190

## Maintenance & Calibration

| Item | Requirement |
|------|-------------|
| **Daily** | Visual and aural checks before use |
| **Subjective calibration** | At least once per week |
| **Objective calibration** | At least once per year |
| **Earphone matching** | Use only earphones provided with unit; serial numbers must match |
| **Cleaning** | Earphones/headband/response switch: disinfecting alcohol before and after each test; LCD: neutral detergent, no alcohol/thinner/benzine |
| **Printer paper** | TP-42 only; avoid vinyl chloride storage |
| **Service life** | Follow manufacturer maintenance schedule |

## Safety Notes

- Audiometers are calibrated per earphone; mismatched serials invalidate performance
- Capable of generating extremely high sound levels; avoid excessive exposure
- Headband is consumable; inspect before each use (loose connection, cracked, damaged)
- Do not disassemble or repair headband
- Install outside patient environment per JIS T0601-1-1 Section 2.202
- Use only Rion-specified fuses and accessories
