## Overview

Cân bệnh nhân điện tử có thước đo chiều cao dùng tại quầy đánh giá ban đầu. Đo cân nặng và chiều cao phục vụ khám Tai Mũi Họng.

## Device Info

| Field | Value |
|-------|-------|
| **Loại** | Cân sàn y tế điện tử (Medical floor scale) |
| **Chức năng** | Cân nặng + đo chiều cao |
| **Max** | 300 kg |
| **Min** | 2 kg |
| **Độ chia (d)** | 100 g (e=d) |
| **Chiều cao** | Có thước đo (80–210 cm) |
| **GTIN** | 04719846012905 |
| **Lot** | MA12460002 |
| **NSX** | 24/08/2024 |
| **Model ref** | DPS-300 (tham khảo) |
| **Tem KĐ** | **206478** (Ngày Hiệu Chưởng) ✅ |
| **Location** | [[tam-anh-clinic-q7.md]] — Khu E Tầng 1, Tai Mũi Họng (Quầy đánh giá ban đầu) |

## Verification Requirements

| Hạng mục | Yêu cầu |
|----------|---------|
| **Chu kỳ kiểm định** | 12–24 tháng (theo TCVN / khuyến cáo nhà SX) |
| **Tiêu chuẩn** | TCVN, OIML R76 (cân phi tự động) |
| **Nội dung** | Kiểm tra độ chính xác với quả cân chuẩn, kiểm tra thước đo chiều cao |
| **Sai số cho phép** | ±1e (±100g) ở tải trọng danh định |
